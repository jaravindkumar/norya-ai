# Norya AI

Norya is an AI receptionist for UK service businesses. It answers calls, uses real business information, checks calendar availability, books appointments, and gives owners a concise call history.

## Local development

1. Copy `.env.example` to `.env.local` and replace placeholders as each integration is enabled.
2. Install dependencies with `pnpm install`.
3. Run `pnpm dev` and open http://localhost:3000.

The health endpoint is available at `/api/health`.
